================================================================================
KEY FINDINGS
================================================================================

Current State:
- 2 active OpenMP parallel regions in C++ (src/jsdm.cpp:398, src/functions.cpp:607)
- No thread capping code (omp_set_num_threads is commented out)
- Non-thread-safe R RNG in both parallel regions
- Global state pollution via .onLoad() setting options(mc.cores = ...)
- Undeclared parallel import in DESCRIPTION

Why It Fails CRAN:
1. Uncapped thread count violates 2-core limit policy
2. RNG thread-safety bug causes intermittent platform-dependent failures
3. Global state changes violate CRAN's package isolation policy
4. Missing dependency declaration (parallel undeclared)

Recommended Solution (Option B):
- Remove OpenMP from C++ entirely
- Parallelize at chain level using parallel::makeCluster() + parLapply()
- Each chain runs in separate R process (inherently thread-safe)
- Fully backward compatible (opt-in cores argument)
- Eliminates all CRAN violations in one architectural change

Benefits of Option B:
✓ Solves all 3 CRAN violations simultaneously
✓ Avoids BLAS + fork deadlock risk
✓ Platform-universal (Windows/macOS/Linux identical)
✓ Reproducible RNG via clusterSetRNGStream()
✓ Near-linear speedup with chain-level parallelism
✓ Easier to understand and debug than OpenMP
✓ No external dependencies (parallel is base R)

BACKWARD COMPATIBILITY
===============================================================================

Default behavior unchanged:
  runOccJSDM(data, MCMCparams = list(nchain = 2, niter = 1000))
  → Uses serial path (cores = 1L by default)
  → Output identical to current code

New feature (opt-in):
  runOccJSDM(data, MCMCparams = list(nchain = 2, niter = 1000), cores = 2L)
  → Uses parallel path with 2 worker processes
  → Output identical to serial path (same seed)

CRAN tests unaffected:
  - R CMD check never passes cores > 1L
  - Examples/vignettes use default cores = 1L
  - No code changes needed in vignettes
  - Output completely identical (no re-rendering needed)
